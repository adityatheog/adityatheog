# Security Policy

## Supported Versions

Currently, this repository does not contain active application code, but if any security issues are
found in relation to the configurations or metadata provided here, they should be reported securely.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report them by sending an email to [adityasutar@proton.me](mailto:adityasutar@proton.me)
or by using the GitHub Private Vulnerability Reporting feature if enabled for this repository.

You should receive a response within 48 hours. If the issue is confirmed, a patch or update will be
issued as soon as possible.
