## Featured projects

### [fyrion](https://github.com/adityatheog/fyrion)

A modular, self-hostable Discord bot platform written in Python.

- Async SQLite persistence with guild-scoped data isolation
- Permission and role-hierarchy guards for moderation workflows
- Optional FastAPI dashboard with OAuth2 sessions
- CI covering `pytest`, `mypy`, `black`, and `flake8`

### [panelkit-bot](https://github.com/adityatheog/panelkit-bot)

A Discord.js v14 interface for Pterodactyl Panel. Users can provision, monitor, and
control their own game servers without opening the panel.

- Shared command registry for prefix and slash commands
- Account-bound server access and sub-user permissions
- Docker, PM2, and systemd deployment paths

### [yukihana](https://github.com/adityatheog/yukihana)

Discord automation and utility services for moderation, scheduled tasks, and quality-of-life commands.

### [messaging-app](https://github.com/adityatheog/messaging-app)

A React and Express messaging prototype with authentication, user discovery, conversation history, and responsive chat UI.

### students · [intro](https://github.com/adityatheog/intro)

Static web projects for student-facing content and personal presentation.
